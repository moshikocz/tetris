# טטריס עץ · 木のテトリス

משחק טטריס בדפדפן: כל המשחק בנוי בעיצוב עץ, וכל ניקוי שורה מפוצץ פרחי דובדבן (סאקורה) בסגנון אנימה יפני.

## הפעלה
פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

## שליטה
| מקש | פעולה |
| --- | --- |
| ← → | הזזה |
| ↑ / X | סיבוב |
| Z | סיבוב נגדי |
| ↓ | ירידה רכה |
| רווח | הפלה מיידית |
| C / Shift | החזקה |
| P / Esc | השהיה |
| B | הפעלה וכיבוי של המוזיקה |
| M | השתקת הכול |

## מגע (טלפון וטאבלט)
| מחווה על הלוח | פעולה |
| --- | --- |
| גרירה לצדדים | הזזה (משבצת לכל משבצת של האצבע) |
| הקשה | סיבוב |
| גרירה איטית למטה | ירידה רכה |
| החלקה מהירה למטה | הפלה |
| החלקה למעלה | החזקה |

יש גם כפתורי מגע מתחת ללוח, כולל כפתור ♪ למוזיקה.

## מה יש בפנים
- כל מרקמי העץ (קיר הקרשים, המסגרת, הלוחות וכל סוג חלק בגוון עץ אחר) נוצרים באופן פרוצדורלי ב-Canvas, בלי קבצי תמונה.
- כל ניקוי שורה מפוצץ פרחי סאקורה, עלי כותרת מעופפים וניצוצות. טטריס (4 שורות) מוסיף פרח ענק, טבעת פרחים, גשם עלי כותרת והודעת 満開!.
- סיבוב SRS עם wall kicks, שק 7 חלקים, חלק רפאים, החזקה, השהיית נעילה, קומבו ושיא שנשמר בדפדפן.
- מוזיקת רקע בסגנון פתיח של אנימה, שמסונתזת בזמן אמת ב-Web Audio: מהלך האקורדים "הדרך המלכותית" (IV–V–iii–vi), בס שמיניות, תופים, ארפג'ים ומלודיה עם הד. בית ופזמון, והקצב עולה עם השלבים.
- צלילי "טוק" של עץ ומנגינת פריטה קצרה בכל ניקוי שורה, באותו סולם של המוזיקה.
